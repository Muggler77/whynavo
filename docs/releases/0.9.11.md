# WhyNavo 0.9.11

## 中文

WhyNavo 0.9.11 修复了编辑器中已选图标与主画布显示不一致的问题。

- 用户明确选择的在线图标现在直接使用保存的图片地址，不再进入自动候选、尺寸筛选、超时切换或失败缓存流程。
- 保存图标后会强制重建对应图标节点，避免继承编辑前的候选索引和失败状态。
- 自动识别仅用于没有明确图标的快捷方式；已选择图标不会在滚动过程中自行变化。
- 保留 0.9.10 的稳定画布、提前加载和原生滚动改进。

## English

WhyNavo 0.9.11 fixes a mismatch where an icon selected in the editor could still appear as a text fallback on the main canvas.

- Explicitly selected online icons now render from the exact saved image URL and bypass automatic candidates, size filtering, timeout switching, and failure caching.
- Saving an icon forces a fresh image node so stale candidate indexes and failure state cannot survive the edit.
- Automatic detection is used only when a shortcut has no explicit icon. A selected icon no longer changes while scrolling.
- The stable canvas, preload, and native scrolling improvements from 0.9.10 remain in place.
