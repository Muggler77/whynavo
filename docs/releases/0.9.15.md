# WhyNavo 0.9.15

## 中文

### 搜索职责与引擎切换

- 主页搜索调整为纯网页搜索，不再显示“搜索应用、网站、笔记和任务”的误导性提示文字。
- 百度 / Google 切换按钮放入主页搜索框内，单击即可切换，选择会作为设置同步。
- 空间页的“搜索网站和文件夹”功能保持不变。
- 搜索页继续保留网站、笔记、任务和网页搜索的全能搜索能力。
- 搜索页的百度 / Google 标签改为框内按钮，也可单击直接切换。
- 桌面和手机端为引擎按钮预留固定宽度，切换时不会挤压输入框或引发布局跳动。

本次更新不修改快捷导航、笔记、任务或同步数据。

## English

### Search responsibilities and engine switching

- Home search is now web-only and no longer displays the misleading “Search apps, sites, notes, and tasks” prompt.
- The Baidu / Google control now sits inside the Home search field and switches with one click. The choice syncs as a setting.
- Spaces keeps its existing site and folder search unchanged.
- The Search page keeps universal local search across sites, notes, tasks, and the web.
- The Search page engine label is now an in-field button that switches directly between Baidu and Google.
- Stable desktop and mobile widths prevent the engine button from squeezing the input or shifting the layout.

This update does not modify shortcut, note, task, or sync data.
