# WhyNavo 0.9.12

## 中文

WhyNavo 0.9.12 修复快捷导航图标被低分辨率图片放大后发虚的问题。

- 图标会按实际显示尺寸和屏幕像素密度检查清晰度。
- 低清位图不会进入主页、空间、搜索结果或文件夹画布。
- 用户已选的低清图标会自动切换到清晰候选；没有清晰资源时使用锐利的文字图标。
- 编辑器不再允许保存清晰度不足的在线候选。
- 虎牙直播改用官方 512 像素应用图标，不再使用 32 像素服务图标。
- 升级后会清理旧的低清解析缓存，不影响网站、文件夹、布局、笔记、任务、壁纸或账号数据。

## English

WhyNavo 0.9.12 fixes shortcut icons becoming blurry when low-resolution artwork is enlarged.

- Icon quality now accounts for rendered size and display pixel density.
- Low-resolution raster images are never painted on Home, Spaces, search results, or folder canvases.
- A selected low-resolution icon falls back to a sharp candidate; when none exists, WhyNavo uses a crisp text icon.
- The editor no longer saves online candidates that fail the sharpness check.
- Huya now uses its official 512-pixel app artwork instead of a 32-pixel service icon.
- The upgrade invalidates old low-resolution icon caches without changing sites, folders, layouts, notes, tasks, wallpapers, or account data.
