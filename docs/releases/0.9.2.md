# WhyNavo 0.9.2

## 中文

WhyNavo 0.9.2 对主页、网站、搜索、笔记、任务和设置界面进行了完整的空间与交互修正。此版本保持数据结构不变，升级不会删除、重建或迁移用户数据。

### 界面与交互

- 主页编辑模式现在直接呈现用户当前的小组件和快捷方式布局，拖动时不再切换为另一套预览结构。
- 主页只保留当前主要内容；更多小组件移动到右键菜单的资源中心，启用后会立即出现在主页。
- 天气组件使用可读的天气状态、风速、降雨和位置表达，移除难以理解的抽象图形。
- 网站页改为无外框、密集且规整的图标画布，仅保留紧凑的圆角“添加网站”操作。
- 修正网站图标的缩放、裁切和对齐，避免图标歪斜、模糊或被额外外框包裹。
- 搜索、笔记和任务工作区统一居中，并补齐添加网站、新建笔记和添加任务操作。
- 设置页改为浮动分段导航和半透明面板；桌面和手机均可完整滚动到底部。
- 右键菜单恢复并提供小组件管理、布局编辑、刷新数据和壁纸操作。

### 语言与稳定性

- 系统界面、资源中心、账户同步、文件夹、导入、时区和安全验证均完整区分中文与英文。
- 用户自行输入的笔记、任务、网站名称和分组名称不会被自动翻译或改写。
- 修复首次启动时 React 严格模式可能重复创建默认笔记和任务的问题。
- 修复手机设置开关变形、按钮错位、横向溢出和长弹窗无法滚动到底部的问题。
- Cloudflare 安全验证框会跟随 WhyNavo 的界面语言。

## English

WhyNavo 0.9.2 completes a spatial and interaction pass across Home, Spaces, Search, Notes, Tasks, and Settings. The data schema is unchanged; upgrading does not delete, rebuild, or migrate user data.

### Interface and interaction

- Home edit mode now uses the user's current widget and shortcut layout instead of switching to a separate preview structure.
- Home stays focused on active content. Additional widgets live in the right-click Resource Center and appear immediately when enabled.
- The Weather widget now uses readable conditions, wind, rain, and location labels instead of an abstract visualization.
- Spaces is now a borderless, dense, aligned icon canvas with a single compact rounded Add Site action.
- Website icon scaling, cropping, and alignment were corrected to avoid skewed, blurry, or unnecessarily framed artwork.
- Search, Notes, and Tasks are centered consistently and include their expected add actions.
- Settings now uses floating segmented navigation and translucent panels, with complete scrolling on desktop and mobile.
- The context menu is restored with widget management, layout editing, data refresh, and wallpaper actions.

### Language and stability

- System UI, Resource Center, account sync, folders, import, time zone, and security verification now separate Chinese and English consistently.
- User-authored notes, tasks, site names, and group names are never translated or rewritten automatically.
- Fixed duplicate default notes and tasks that could be created during first boot under React Strict Mode.
- Fixed malformed mobile toggles, misplaced actions, horizontal overflow, and long dialogs that could not scroll to the bottom.
- The Cloudflare security verification frame now follows the selected WhyNavo language.
