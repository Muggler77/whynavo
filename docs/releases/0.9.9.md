# WhyNavo 0.9.9

## 中文

WhyNavo 0.9.9 修复快捷导航编辑器中“已经选择并保存图标，但最终仍显示文字或切换到其他图标”的问题。现有网站、文件夹、主页位置、笔记、任务、小组件、壁纸、账号和同步数据都会保留。

- 用户明确选择的在线图标现在会作为固定图标保存，不再重新进入自动候选解析流程。
- 用户选择的图标只要能够成功加载就会被采用，不再被自动采集使用的高清尺寸门槛误判。
- 图标编辑器预览改为立即加载；保存、重新打开编辑器和等待后的图标来源保持一致。
- 未指定图标时仍使用浏览器本地图标、站点图标和安全回退组成的自动采集流程。

## English

WhyNavo 0.9.9 fixes a shortcut editor bug where a selected and saved icon could still render as text or switch to a different candidate. Existing sites, folders, Home positions, notes, tasks, widgets, wallpapers, accounts, and synchronized data are preserved.

- A user-selected online icon is now stored as a fixed choice and no longer re-enters automatic candidate resolution.
- Any explicitly selected icon that loads successfully is accepted instead of being rejected by the high-resolution threshold used for automatic detection.
- The shortcut editor preview now loads immediately, and the icon source remains stable after saving, reopening the editor, and waiting.
- Shortcuts without an explicit icon continue to use Chrome's local favicon source, site artwork, and safe automatic fallbacks.
