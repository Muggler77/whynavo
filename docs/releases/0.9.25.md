# WhyNavo 0.9.25

## English

- Removes the Cloudflare Turnstile HTML, CSS, and JavaScript from the Manifest V3 extension package. The CAPTCHA document is now a web-hosting-only asset and cannot be copied into the Chrome Web Store ZIP.
- Adds a package audit that rejects remotely hosted script tags, remote worker/module imports, the Turnstile vendor program URL, and every web-only CAPTCHA/search file.
- Routes Home and Search page network queries through `chrome.search.query` with `CURRENT_TAB`, so Chrome always uses the default search provider selected by the user.
- Removes the Baidu/Google switch and the search-provider setting from the new-tab interface. WhyNavo does not alter Chrome's default search provider.
- Keeps local Spaces filtering and Search page results for sites, notes, and tasks unchanged.
- Adds a website-only search redirect for the hosted app without placing provider URLs or executable web-only files in the extension package.
- Pins Nano ID 6.0.0 in the Node 22+ build toolchain to remove GHSA-2v37-7h3g-55p8; Nano ID is not shipped as extension runtime code.

## 中文

- 从 Manifest V3 扩展安装包中彻底移除 Cloudflare Turnstile 的 HTML、CSS 和 JavaScript；验证码页面现在仅属于官网部署资源，不会再进入 Chrome 应用商店 ZIP。
- 新增安装包硬性审计：发现远程脚本标签、远程 Worker/模块导入、Turnstile 远程程序地址，或任何官网专用验证码/搜索文件时，构建会直接失败。
- 主页和搜索页的联网搜索统一改为 `chrome.search.query`，并使用 `CURRENT_TAB`，因此始终尊重用户在 Chrome 中选择的默认搜索服务。
- 删除新标签页中的百度/Google 切换按钮和搜索服务设置；WhyNavo 不会修改 Chrome 的默认搜索服务。
- 空间页本地查找，以及搜索页对网站、笔记和任务的本地结果保持不变。
- 在线版保留独立的官网搜索跳转页，但搜索服务地址和官网专用可执行文件不会进入扩展安装包。
- 在 Node 22+ 构建链中将 Nano ID 固定到 6.0.0，清除 GHSA-2v37-7h3g-55p8；Nano ID 不会作为扩展运行时代码发布。
