# WhyNavo 0.9.27

WhyNavo 0.9.27 refines the responsive canvas and makes search-provider switching visually stable across desktop, zoomed, and mobile layouts.

## 中文

- 搜索引擎控件使用固定宽度槽位，切换“默认/百度”时不会挤压或推动输入框。
- 搜索控件保留 Chrome 默认搜索为初始选项；百度仍是用户主动选择的次级选项，不修改浏览器设置。
- 搜索控件在主页和全能搜索页使用同一套紧凑、通透的视觉语言，并修正按钮的中英文无障碍名称。
- 桌面画布采用更接近参考布局的 80% 视口比例；浏览器缩放时左右留白平滑变化。
- 701–760 像素的平板与横屏区间恢复满宽布局，避免桌面规则压缩移动导航和内容。

本版本不改变数据模型、同步协议或用户数据格式。

## English

- The search-provider control now reserves a fixed-width slot, so switching between Default and Baidu never pushes the query field around.
- Chrome's default search remains the initial option; Baidu is still an explicit secondary choice and never changes browser settings.
- Home and universal search use the same compact, translucent control language, with provider-specific accessible names and titles.
- The desktop canvas follows an approximately 80% viewport ratio, keeping side gutters visually stable while users zoom.
- Tablet and landscape widths from 701 to 760 pixels return to a full-width layout so desktop rules do not squeeze mobile navigation or content.

This release does not change the data model, synchronization protocol, or user data format.
