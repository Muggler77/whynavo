# WhyNavo 0.9.3

## 中文

WhyNavo 0.9.3 修复 0.9.2 中仍然存在的主页散点图标、天气预报辨识度和桌面页面偏左问题。数据结构保持不变，升级不会删除、重建或迁移用户数据。

- 删除空白主页中的推荐网站散点布局；没有用户网站时，主页只保留主要小组件。
- 用户添加的网站统一使用等尺寸、等间距网格，并继续支持布局编辑和拖动排序。
- 删除 X、GitHub 等推荐图标的特殊圆形背景、反色和不一致尺寸规则。
- 天气预报根据真实天气代码显示晴、多云、雾、雨、雪和雷雨图标，并同时显示中文或英文天气名称。
- 当前天气主图标也会跟随实际天气状态，不再固定显示同一个符号。
- 桌面主页、网站、搜索、笔记和任务工作区以整个视口中心线为准，不再受左侧或右侧导航位置影响。
- 在 2048px 桌面测试中，主页、搜索标题、搜索内容、笔记、任务和网站画布的中心偏差均为 0px。
- 手机端网站区域取消固定最小高度，少量图标不会再产生大块无意义空白；390px 测试无横向溢出。

## English

WhyNavo 0.9.3 fixes the remaining scattered Home icons, unclear weather forecast symbols, and left-shifted desktop workspaces from 0.9.2. The data schema is unchanged; upgrading does not delete, rebuild, or migrate user data.

- Removed the decorative starter-site scatter from an empty Home page; only the primary widgets remain when the user has no sites.
- User-created sites now use an equal-size, evenly spaced grid while preserving layout editing and drag reordering.
- Removed special circular backgrounds, inversion, and inconsistent sizing for X and GitHub starter artwork.
- Forecast days now map real weather codes to familiar clear, cloudy, fog, rain, snow, and thunderstorm icons with visible localized condition labels.
- The current-weather illustration also follows the actual condition instead of always showing the same symbol.
- Home, Spaces, Search, Notes, and Tasks now align to the viewport center independently of left or right navigation placement.
- At a 2048px desktop viewport, measured center offset is 0px for Home, Search heading and content, Notes, Tasks, and the Spaces canvas.
- Removed the fixed mobile minimum height for the sites area, avoiding empty space with only a few icons; the 390px layout has no horizontal overflow.
