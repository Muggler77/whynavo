# WhyNavo 0.9.34

WhyNavo 0.9.34 makes the Settings update experience accurate and easier to understand while correcting icon alignment in appearance controls.

## 中文

- 修正设置中时区按钮的 SVG 与文字基线偏差，桌面和手机宽度下都使用稳定的垂直居中布局。
- 版本页同时展示“自动更新”和“手动安装”，并清楚标记当前渠道、可用条件和备用方式。
- 本地未打包版会如实说明 Chrome 无法自动更新；选择自动更新会前往官方 Chrome 商店安装渠道。
- Chrome 商店正式安装版仍由 Chrome 在后台自动更新，也可以从版本页主动请求一次更新检查。
- 网页版继续在刷新后使用最新版；手动发布包只作为浏览器扩展的安装方式。
- 中英文、桌面布局、375px 窄屏、浅色与深色模式均已检查，没有新增权限、远程代码、数据格式或同步逻辑变更。
- 0.9.34 与 0.9.33 使用相同的数据架构和同步协议，最低支持版本继续保持 0.9.32。

本版本不会重置快捷方式、文件夹、主页位置、小组件、笔记、任务、壁纸、账号或同步数据，也不会取消或覆盖 Chrome 商店中正在审核的 0.9.32。

## English

- Corrects the SVG-to-text baseline mismatch in the Settings time-zone control with stable vertical centering on desktop and mobile.
- Shows Automatic and Manual update channels together, with the active channel, availability condition, and fallback path clearly labeled.
- Explains that local unpacked builds cannot be auto-updated by Chrome; selecting Automatic opens the official Chrome Web Store installation channel.
- Keeps official Chrome Web Store installations on Chrome-managed background updates while allowing an immediate update check from Settings.
- Keeps the hosted app on refresh-to-latest behavior; manual packages remain an extension installation path only.
- Verifies both languages, desktop, 375px, light, and dark layouts. No permissions, remote code, data schema, or synchronization behavior changed.
- Version 0.9.34 uses the same data schema and sync protocol as 0.9.33, so the compatibility floor remains 0.9.32.

This release does not reset shortcuts, folders, Home positions, widgets, notes, tasks, wallpapers, accounts, or synchronized data, and it does not cancel or replace the Chrome Web Store review of 0.9.32.
