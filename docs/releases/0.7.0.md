# WhyNavo 0.7.0

WhyNavo 0.7.0 is the brand migration release. It moves the product, release assets, documentation, hosted-app configuration, and public repository links to the WhyNavo name while preserving existing local and synchronized user data.

## Data safety

- Existing browser data is copied into the WhyNavo local database before the new version reads or writes it. Existing records win if the new database already contains the same key.
- Cloud session-policy function identifiers are migrated in place. Sync snapshots, account IDs, Auth accounts, revisions, and backup data are not recreated or moved.
- Previous browser clients remain isolated from the new local database; they cannot overwrite a current WhyNavo partition.

## Product identity

- The extension, PWA, update manifest, release archive, Pages configuration, email templates, legal notices, GitHub links, and automation workflows now use WhyNavo.
- The official hosted address is prepared as `https://whynavo.pages.dev/`. It must be created in Cloudflare Pages and applied to Supabase Auth before this release is activated for public users.

## Design planning

- Added the WhyNavo redesign proposal and a persistent design-system baseline.
- The next visual release will use a flexible personal canvas, independent navigation rail, clear high-quality favicon presentation, and widgets with genuinely different visual identities.
