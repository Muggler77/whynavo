# WhyNavo 0.9.6

## 中文

WhyNavo 0.9.6 完成主页小组件、搜索、设置和深色主题的系统性修复。现有网站、文件夹、图标位置、笔记、任务、壁纸、账号与同步数据均会保留。

- 主页不再只显示前三个已启用组件；资源中心启用的每个组件都会真实出现在主页。
- 紧凑、标准和展开尺寸现在同时控制组件宽度、高度与信息密度。12 个组件均按三种尺寸完成适配，天气紧凑版不再出现大块空白。
- 新用户默认使用天气、专注、日历三组件布局。只对从未自定义过的旧默认组件组合执行同等迁移，用户自行启用或关闭的组件保持不变。
- 主页显示当前时间与日期；主页搜索只保留一个明确的提交按钮。
- 搜索引擎统一在设置中选择，主页和搜索页遵循同一个百度或 Google 设置。
- 城市改为中英文城市下拉列表；时间设置会实时显示当前时区时间。
- “编辑主页布局”移入主页右键菜单，原固定左下角按钮已移除；右键仍可控制图标浮动、组件库、刷新和壁纸。
- 设置增加带当前预览的壁纸入口，可直接打开完整壁纸库。
- 设置行、下拉框、开关和导航标签重新对齐，桌面和手机均可无阻滚动到底部。
- 深色主题重建文字、边框、输入框、弹窗、资源中心和组件表面的对比度。
- 修复本地优先提示在滚动时覆盖组件的问题，并为上传图片的错误提示补齐中英文切换。
- 为避免旧客户端继续隐藏已启用组件或用旧的主页归一化规则回写状态，最低同步版本提升为 0.9.6；旧版会明确提示升级。

## English

WhyNavo 0.9.6 delivers a systematic fix for Home widgets, search, Settings, and dark mode. Existing sites, folders, icon positions, notes, tasks, wallpapers, account data, and synchronized data remain intact.

- Home no longer truncates enabled widgets to the first three. Every widget enabled in the Resource Center now renders on Home.
- Compact, standard, and expanded sizes now control width, height, and information density. All 12 widgets are adapted to all three sizes, including a complete compact Weather card without unused space.
- New users start with Weather, Focus, and Calendar. The same migration applies only to the untouched legacy default widget set; explicit user choices remain unchanged.
- Home now shows the current time and date, and its search field has one clear submit action.
- The search engine is selected in Settings. Home and Search consistently follow the same Baidu or Google preference.
- Weather city selection uses a bilingual city dropdown, and the time setting previews the active time zone live.
- Edit Home layout moved into the Home context menu. The fixed lower-left control was removed, while icon motion, widgets, refresh, and wallpaper actions remain available from right-click.
- Settings includes a wallpaper row with the current preview and opens the complete wallpaper library directly.
- Settings rows, selects, switches, and navigation labels are aligned consistently and scroll fully on desktop and mobile.
- Dark mode now uses legible text, borders, inputs, dialogs, Resource Center surfaces, and widget colors.
- The local-first footer no longer covers widget rows while scrolling, and image-upload errors now follow the selected interface language.
- The minimum synchronization version is now 0.9.6 so older clients cannot keep hiding enabled widgets or write back the previous Home normalization behavior; older builds show an explicit update notice.
