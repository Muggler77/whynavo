# WhyNavo 0.9.26

WhyNavo 0.9.26 improves wide-screen and browser-zoom layout behavior, makes every shortcut navigation explicit and reliable, and adds a policy-safe optional Baidu search choice.

## 中文

- 桌面主页、网站空间、搜索、笔记和任务画布使用随有效视口增长的流式宽度；浏览器缩小页面比例时，左右留白会同步收缩，不再被固定的 1274px 画布锁住。
- 宽屏下主页的网站区和小组件区按比例重新分配空间；原有数据、图标位置、组件尺寸和同步结构保持不变。
- 搜索框首项和初始状态始终是 Chrome 默认搜索引擎，并通过 `chrome.search.query` 使用 `NEW_TAB` 打开。
- 搜索框可由用户主动选择百度进行单次搜索；该选择不写入设置、不修改 Chrome 默认搜索服务，并在新标签页打开。
- 主页、网站空间、搜索结果、文件夹、Dock 和右键菜单中的网站入口统一强制新标签页打开，当前标签页不会被替换。
- 更新隐私说明、Chrome 商店审核说明和自动化回归检查，明确搜索词只发送给用户选择的搜索服务。

本版本不改变数据模型和同步逻辑，不需要用户迁移或重新注册。

## English

- Home, Spaces, Search, Notes, and Tasks now use a fluid content width that grows with the effective viewport. Zooming the browser out reduces the side gutters instead of leaving the UI trapped in a fixed 1274px canvas.
- Wide layouts proportionally give more room to the Home site canvas and widgets while preserving existing data, positions, widget sizes, and sync structures.
- Chrome's default provider remains the first and initial search option, and default searches use `chrome.search.query` with `NEW_TAB`.
- Users can explicitly choose Baidu for an individual query. The choice is not stored, does not modify Chrome's default provider, and opens in a new tab.
- Home shortcuts, Spaces, local Search results, folders, the Dock, and context-menu site actions all reliably open in a new tab without replacing the current tab.
- Privacy, store-review notes, and automated safety checks now document exactly which provider receives an explicitly submitted query.

This release does not change the data model or synchronization logic and requires no migration or re-registration.
