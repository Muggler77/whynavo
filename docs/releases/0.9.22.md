# WhyNavo 0.9.22

## English

- Fixes wallpaper selection so a chosen wallpaper is applied immediately, visibly marked as selected, and preserved after reload.
- Serializes local settings writes and saves the latest state when the page is hidden or closed, preventing rapid changes from being overwritten by an older write.
- Makes settings explicitly instant and automatic, with clear saved-state feedback instead of a separate save step.
- Adds live customization for shortcut-label color and shadow, including a wallpaper-backed preview and accessible shadow choices.
- Extends state validation, migration defaults, and concurrent-sync tests to protect the new appearance settings across upgrades and devices.

## 中文

- 修复壁纸选择后不切换的问题：点击后立即生效、明确显示选中状态，并在刷新后继续保留。
- 串行处理本机设置写入，并在页面隐藏或关闭时保存最新状态，避免快速连续修改被较早的写入覆盖。
- 所有设置改为明确的点击即生效、自动保存，并提供清晰的保存状态反馈，不再需要单独保存。
- 新增快捷图标文字颜色与阴影的实时自定义，并提供结合当前壁纸的预览和清晰可访问的阴影选项。
- 补充状态校验、迁移默认值和并发同步测试，确保新外观设置在升级及多设备之间安全保留。
