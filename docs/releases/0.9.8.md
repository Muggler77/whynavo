# WhyNavo 0.9.8

## 中文

WhyNavo 0.9.8 集中修复网站图标识别、搜索空态、主页时钟和文件夹体验。现有网站、文件夹内容、主页位置、笔记、任务、小组件、壁纸、账号和同步数据都会保留。

- Chrome 扩展优先使用浏览器本机 Favicon API 获取用户实际访问过的网站图标，不再只依赖第三方在线服务。
- 图标解析会优先寻找清晰图标，并在没有高清资源时保留可辨认的低分辨率站点图标作为最后回退。
- 图标编辑器会隐藏加载失败的候选，不再显示整排“不可用”占位；仍可改用纯色文字图标或本地上传。
- 搜索页移除并非真实历史的“最近使用”列表，空白状态只保留添加网站入口，输入关键词后再显示本地结果。
- 主页时钟放大并显示到秒，日期继续保持次级视觉层级。
- 文件夹重做为参考图式的居中磨砂图标画布：标题悬浮于面板上方，图标密集规整，添加、编辑和关闭操作保持可访问。
- 文件夹在手机端使用完整可滚动底部面板，并适配深色主题、系统安全区和减少动态效果设置。

## English

WhyNavo 0.9.8 focuses on site icon detection, the Search empty state, the Home clock, and the folder experience. Existing sites, folder contents, Home positions, notes, tasks, widgets, wallpapers, accounts, and synchronized data are preserved.

- The Chrome extension now prefers Chrome's local Favicon API for sites the user has actually visited instead of relying only on third-party icon services.
- Icon resolution prefers sharp artwork while retaining a recognizable lower-resolution site icon as a last resort when no high-resolution source exists.
- Failed candidates disappear from the icon editor instead of filling it with unavailable placeholders. Text icons and local uploads remain available.
- Search no longer presents the first items as a fake Recently used history. Its empty state keeps only Add site, and local results appear after a query is entered.
- The Home clock is larger and includes seconds while the date remains visually secondary.
- Folders now use a centered frosted icon canvas inspired by the reference: the title floats above a dense, orderly grid while add, edit, and close controls remain accessible.
- Mobile folders use a fully scrollable bottom panel with dark-theme, safe-area, and reduced-motion support.
