# WhyNavo 0.9.32

WhyNavo 0.9.32 adds device-local dynamic wallpapers and makes the product's local-first promise visible before a visitor is asked to install or sign in.

## 中文

- 支持上传 MP4 与 WebM 动态壁纸，单个文件最多 100 MB、2 分钟、4K；上传后生成静态封面，并以静音、循环、行内视频方式播放。
- 动态壁纸视频作为独立 Blob 保存在当前浏览器的 IndexedDB 中，状态数据只保存轻量元数据和封面，不进入云端同步快照。
- 页面进入后台时自动暂停视频；系统开启“减少动态效果”时只显示静态封面；壁纸库提供“播放动态效果”开关。
- 删除动态壁纸会清理本机视频；未登录数据并入账号时会原子迁移对应媒体；永久删除账号会清理该账号的本机动态壁纸。
- JSON 数据备份不嵌入动态壁纸视频字节，导出界面、隐私说明和备份清单都会明确提示；在新设备上需要重新选择视频文件。
- 官网导航背景改为完整覆盖视口宽度，修复超宽屏或缩放后两端突然截断的问题。
- 官网中英文首屏直接说明“无需登录、本地优先、登录仅增加可选同步”，并保留云同步不是端到端加密的准确边界。

本版本不会重置快捷方式、文件夹、主页位置、小组件、笔记、任务、静态壁纸、账号或同步数据。用户提供的参考视频仅用于本机兼容性验证，不包含在源代码、构建产物或发布包中。

## English

- Adds MP4 and WebM dynamic wallpaper uploads with a 100 MB, two-minute, and 4K boundary. The app generates a static poster and plays the selected video muted, looped, and inline.
- Stores video bytes as a separate Blob in the current browser's IndexedDB. App state contains only bounded metadata and a poster; video bytes never enter cloud snapshots.
- Pauses playback when the page is hidden, shows only the poster under reduced-motion preferences, and provides a Play motion switch in the wallpaper library.
- Cleans local video media when a wallpaper or account is deleted and atomically moves anonymous video media when local data is adopted into an account.
- Keeps video bytes out of JSON data backups and explains that boundary in the export UI, privacy notice, and backup manifest. Users select the original video again on a new device.
- Makes the marketing-site header background span the full viewport, fixing abrupt ends on wide or zoomed layouts.
- Moves the no-account, local-first promise into the first viewport in both languages while keeping the honest boundary that cloud synchronization is not end-to-end encrypted.

This release does not reset shortcuts, folders, Home positions, widgets, notes, tasks, static wallpapers, accounts, or synchronized data. The user-provided compatibility video is not included in the source tree, build output, or release archive.
