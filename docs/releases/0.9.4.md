# WhyNavo 0.9.4

## 中文

WhyNavo 0.9.4 恢复并重做了主页“我的网站”自由画布，修复小组件尺寸不一致，并新增 WeTab 数据迁移与固定任务提醒。现有网站、笔记、任务和同步数据会原样保留；新字段均为可选字段。

- “我的网站”始终保留，用户图标可在编辑布局时自由拖动，位置会本机保存并随账号同步。
- 右键网站可继续编辑或替换图标；右键主页空白区域可开启或关闭低幅度浮动效果，系统减少动态效果时会自动停用动画。
- 小组件的紧凑、标准、展开尺寸在设置预览、普通显示和布局编辑中使用同一套实际宽度。
- 导入器新增 WeTab `.data` 支持，保留分类、文件夹、顺序、网址和安全的 HTTPS 图标，同时忽略无法迁移的 WeTab 专属小组件。
- 已知品牌优先使用清晰矢量图标，其他网站继续使用高清 favicon、多级回退、懒加载和有界本机缓存。
- 任务新增每天、工作日和可选择星期的每周固定类型，可选固定时间提醒；Chromium 扩展关闭页面后仍由浏览器后台定时提醒，普通网页和移动端 PWA 需要页面保持打开，通知权限仅在用户主动设置提醒时申请。
- 固定任务完成后只标记当天，下一次到期时会自动重新开放，不会被永久删除。
- 笔记继续保存在浏览器管理的账号分区 IndexedDB 中，并新增通用 Markdown 导出。
- 隐私说明增加本地任务提醒副本与浏览器通知权限说明，法律文档版本更新为 2026-07-28。
- 因旧客户端的严格校验不认识固定任务与自由位置字段，最低同步版本提升为 0.9.4；旧设备升级前不会继续写入新版云端快照。

## English

WhyNavo 0.9.4 restores and rebuilds the Home “My Sites” free-position canvas, fixes widget-size inconsistency, and adds WeTab migration plus recurring task reminders. Existing sites, notes, tasks, and synchronized data remain intact; every new data field is optional.

- My Sites remains visible and user icons can be freely positioned in layout editing; positions are stored locally and synchronized with the account.
- Right-click a site to edit or replace its icon. Right-click empty Home space to toggle subtle icon motion; reduced-motion preferences disable it automatically.
- Compact, Standard, and Expanded widgets now use the same physical widths in the picker, normal Home view, and layout editing.
- The importer now accepts WeTab `.data`, preserving categories, folders, order, URLs, and safe HTTPS icons while ignoring nonportable WeTab-only widgets.
- Known brands prefer crisp vector marks; other sites retain high-resolution favicon lookup, bounded fallbacks, lazy loading, and local caching.
- Tasks now support daily, weekday, and weekday-selectable weekly recurrence with an optional fixed-time reminder. Chromium extension alarms continue while the new-tab page is closed; the regular website and mobile PWA require the page to remain open. Notification permission is requested only after the user chooses a reminder.
- Completing a recurring task marks only the current day; it reopens on its next due date instead of being deleted permanently.
- Notes remain in browser-managed, account-partitioned IndexedDB and can now be exported as portable Markdown.
- The privacy notice now documents the local reminder copy and browser notification permission; the legal document version is 2026-07-28.
- Because older strict validators do not recognize recurring-task and free-position fields, the minimum synchronization version is now 0.9.4; older devices stop before writing a newer cloud snapshot until upgraded.
