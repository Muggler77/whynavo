# WhyNavo 0.9.14

## 中文

### 更高的图标采集成功率

- 图标显示改为三级质量策略：高清位图全尺寸显示；48–191 像素的可识别图标按设备像素密度缩小居中显示；低于 48 像素才使用文字回退。
- 紧凑图标不会被拉伸。WhyNavo 按图片原生像素预算计算显示尺寸，在高分屏上也不会产生放大模糊。
- 恢复 Google favicon 作为自动候选来源，但不会把其地址保存成用户选定图标，也不会恢复 Chrome 的强制重采样接口。
- 增加常见的 512 像素、192 像素和 PNG 网站图标路径，提高新站点识别成功率。
- 图标解析缓存现在同时记录高清或紧凑显示模式。滚动、换页和重新挂载时不会先拉伸再缩小，也不会反复变化。
- 旧版图标解析缓存自动失效并按新规则重建。

本次更新不修改快捷导航、笔记、任务、设置或同步数据。

## English

### Higher icon discovery success

- Icon rendering now uses three quality levels: high-resolution rasters fill the tile, recognizable 48–191 pixel artwork is centered at a device-density-safe size, and only images below 48 pixels fall back to text.
- Compact artwork is never stretched. WhyNavo calculates its display size from the source pixel budget, including on high-density screens.
- Google favicon discovery is restored as an automatic candidate, but provider URLs are never persisted as user-selected artwork and Chrome's forced resampling endpoint remains disabled.
- Added common 512 pixel, 192 pixel, and PNG site-icon paths to improve discovery for new sites.
- The resolution cache now records full or compact presentation. Icons do not stretch briefly, change while scrolling, or get reclassified on remount.
- Older resolution caches are invalidated and rebuilt under the new policy.

This update does not modify shortcut, note, task, setting, or sync data.
