# WhyNavo 0.9.19

## 中文

- 包含 0.9.18 的全部隐私说明、专用支持页、Chrome 商店截图与最小权限清理。
- 为 Cloudflare R2 私有加密备份增加 35 天自动删除规则，并在配置后通过 API 回读验证。
- 修复增量发布门禁：已经完成旧同步接口停用后，后续版本不会要求重新开放该接口。
- 保持 `0.9.17` 为灰度部署期间唯一可信的公开前序版本，正式激活后再切换到 `0.9.19`。

## English

- Includes all 0.9.18 privacy disclosure, dedicated support page, Chrome Web Store screenshot, and least-privilege permission cleanup.
- Adds and API-verifies a 35-day deletion lifecycle for private encrypted Cloudflare R2 backups.
- Fixes the incremental release gate so a previously retired legacy sync endpoint is never reopened for later releases.
- Keeps `0.9.17` as the only trusted public predecessor during staged deployment, then activates `0.9.19` after release verification.
