# WhyNavo 0.9.28

WhyNavo 0.9.28 makes web-search selection clearer and gives the Spaces canvas more room on wide desktop displays. The release does not change the data model, synchronization protocol, or backup format.

## 中文

- 搜索框左侧改为固定宽度的网页搜索入口，点击后展开通透的下拉面板，显示当前选项、说明和选中状态。
- 设置页增加同一套网页搜索下拉选择；选择只作用于当前页面会话，不写入账号同步数据，也不修改 Chrome 默认搜索设置。
- Chrome 默认搜索始终排在第一项，并继续通过 `chrome.search.query` 使用用户在 Chrome 中配置的默认服务；百度只有在用户主动选择后才会打开。
- 下拉面板支持鼠标、触摸、Tab、方向键、Home、End 和 Escape，切换时不会推动输入框或改变搜索框宽度。
- 宽屏“空间”页面扩展到约 92% 视口宽度，减少右侧空白；主页、搜索页、移动端和数据格式保持不变。

## English

- The search field now uses a fixed-width provider trigger with a translucent dropdown that shows the current option, explanation, and selected state.
- Settings exposes the same provider choice. It applies only to the current page session, is excluded from synchronized account data, and never changes Chrome's default search setting.
- Chrome default search remains the first option and continues through `chrome.search.query`, using the provider configured in Chrome. Baidu opens only after an explicit user choice.
- The menu supports mouse, touch, Tab, arrow keys, Home, End, and Escape without moving the query field or changing the search control width.
- Wide desktop Spaces expands to approximately 92% of the viewport to reduce the right-side dead space; Home, Search, mobile layouts, and data formats are unchanged.

The release remains within the single-purpose new-tab policy boundary: it does not override Chrome settings, inject content scripts, or add remote code.
