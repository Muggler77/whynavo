# WhyNavo 0.9.29

WhyNavo 0.9.29 aligns the wide-screen header and Spaces canvas, makes the Add site action sit on the same edge as the shortcut grid, and presents the initial web-search option as Google while preserving Chrome's policy-safe search API behavior.

## 中文

- 宽屏顶部品牌与语言、主题、账号操作组改为和“空间”图标画布共用同一条内容边缘，左右留白更均衡。
- “添加网站”按钮与图标网格使用相同的内侧间距，按钮不再单独漂移到另一条对齐线上。
- 搜索控件和设置中的初始搜索选项统一显示为 Google，并使用本地内置的 Google SVG 图标。
- Google 选项底层仍通过 `chrome.search.query` 遵循浏览器当前默认搜索设置；百度仍只有在用户主动选择后才打开，不修改浏览器设置。
- 本版本不改变数据 schema、同步协议、备份格式或用户数据迁移路径。

## English

- On wide screens, the brand and the language, theme, and account actions now share the same content edge as the Spaces icon canvas for balanced gutters.
- The Add site action uses the same inner inset as the shortcut grid, so it no longer sits on a separate alignment line.
- The initial provider is labeled Google in both the search control and Settings, with the bundled local Google SVG mark.
- The Google-labelled option still uses `chrome.search.query` and follows the browser's current default search setting; Baidu opens only after an explicit user choice and never changes browser settings.
- This release does not change the data schema, synchronization protocol, backup format, or user-data migration path.
