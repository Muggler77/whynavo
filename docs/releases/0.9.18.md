# WhyNavo 0.9.18

## 中文

- 删除不再使用的 Chrome `search` 权限；主页和搜索页继续通过用户选择的百度或 Google HTTPS 搜索地址打开结果。
- 更新商店权限说明，明确扩展不读取浏览历史、不注入内容脚本，也不申请全站访问权限。
- 增加正式双语支持页，公开问题与包含个人数据或安全信息的问题使用不同联系渠道。
- 更新中英文隐私说明，披露每日生产数据库导出会先加密再保存到私有 Cloudflare R2，最长保留 35 天，并明确账号删除与灾难恢复规则。
- 新注册会记录 `2026-08-01` 版隐私说明与服务条款的同意版本。
- 修正灰度发布的前序版本清单，使 `0.9.18` 部署期间只保留当前公开的 `0.9.17`，不会临时回退到更旧版本。
- 本次更新不修改用户数据结构，不删除、重排或重新归属快捷方式、文件夹、笔记、任务、小组件和账号数据。

## English

- Removed the unused Chrome `search` permission. Home and Search still open the user-selected Baidu or Google HTTPS result page.
- Updated the store permission disclosure to confirm that the extension does not read browsing history, inject content scripts, or request broad website access.
- Added a dedicated bilingual support page with separate channels for public questions and matters involving personal data or security.
- Updated the bilingual privacy notice to disclose daily pre-upload encrypted production database backups in private Cloudflare R2 storage, a maximum 35-day retention period, and the account-deletion disaster-recovery rules.
- New registrations record acceptance of the `2026-08-01` privacy notice and terms version.
- Corrected the staged-release predecessor manifest so the `0.9.18` rollout retains the currently public `0.9.17` manifest instead of temporarily advertising an older release.
- This release does not change the user-data schema or delete, reorder, or reassign shortcuts, folders, notes, tasks, widgets, or account data.
