# WhyNavo 0.9.1

## 中文

WhyNavo 0.9.1 重做 Spaces 网站页的信息密度和图标采集体验，并加入可同步的中英文界面设置。数据结构保持不变，升级不会删除或重建用户数据。

### 网站页

- 移除网站区域外围卡片、边框和多余背景，让分类和网站图标直接排布在通透画布上。
- 桌面端使用紧凑分类栏和自适应图标网格；手机端改为横向分类栏和稳定的多列布局。
- 网站页搜索框可以即时筛选网站、网址、文件夹及文件夹内的网站。
- 图标、标题和拖拽区域使用固定响应式尺寸，避免图片、文字重叠和布局跳动。

### 图标稳定性

- 优先请求高清站点图标，再使用品牌矢量图、网站原始图标和本机首字母回退。
- 主界面继续拒绝低分辨率位图，避免模糊图标被放大展示。
- 修复采集图标弹窗把小尺寸候选误判为失败的问题；候选预览采用独立阈值、固定尺寸和去重顺序。
- 外部图标仍由 Service Worker 限量缓存，减少重复下载和长期内存压力。

### 中英文与交互

- 顶栏和设置均可切换简体中文或 English；选择会保存在本机并随账号设置同步。
- 主页、Spaces、Search、Notes、Tasks、设置、站点编辑和主要右键菜单支持双语界面。
- 用户自己创建的分类、网站、笔记和任务保持原文，不会因切换语言被改写。
- 修复新增网站弹窗标题误显示为“编辑网站”的问题，并复核网站右键菜单可用。

### 兼容性

- 数据结构版本保持为 1；快捷方式、文件夹、笔记、任务、组件、布局和账号分区均保持兼容。
- 本机优先存储、账号隔离、冲突安全同步和完整备份逻辑没有改变。

## English

WhyNavo 0.9.1 rebuilds the information density of Spaces and the collected-icon experience, and adds a synchronized Chinese/English interface preference. The data schema is unchanged, so upgrading does not delete or rebuild user data.

### Spaces

- Removes the outer card, border, and redundant panel background so categories and site icons sit directly on the translucent canvas.
- Uses a compact category rail and responsive icon grid on desktop, plus a horizontal category strip and stable multi-column layout on mobile.
- Adds instant filtering across site names, URLs, folders, and sites inside folders.
- Gives icons, labels, and drag targets stable responsive dimensions to prevent overlap and layout shifts.

### Icon reliability

- Tries a high-resolution site icon first, then a curated brand vector, direct site artwork, and the local monogram fallback.
- Continues rejecting low-resolution raster images in the main interface so blurred artwork is not enlarged.
- Fixes collected-icon previews being rejected by the main-view size threshold; previews now use their own threshold, fixed cells, and deduplicated ordering.
- External icons remain bounded by the Service Worker cache to reduce repeated downloads and long-term resource use.

### Language and interaction

- Simplified Chinese and English can be switched from the top bar or Settings; the preference is stored locally and included in account settings sync.
- Home, Spaces, Search, Notes, Tasks, Settings, site editing, and primary context menus support both languages.
- User-created categories, sites, notes, and tasks remain unchanged when the interface language changes.
- Fixes the new-site dialog incorrectly showing an edit title and revalidates shortcut context menus.

### Compatibility

- The data schema remains version 1; shortcuts, folders, notes, tasks, widgets, layout, and account partitions remain compatible.
- Local-first storage, account isolation, conflict-safe sync, and full-backup behavior are unchanged.
