# WhyNavo 0.9.31

WhyNavo 0.9.31 removes the oversized empty Home canvas gap, keeps Settings complete at every supported width, and explains when the web app or desktop extension is the right choice.

## 中文

- 主页没有网站时，不再永久保留一整列空画布；“我的网站”改为紧凑添加入口，小组件会自然使用主内容宽度。
- 添加网站后仍保留原有自由定位图标画布，不改变用户已经保存的网站位置。
- 设置窗口限制为单一纵向滚动区域，所有控件都会适应自身可用宽度，不再出现右侧裁切或横向滚动。
- 已验证 375、768、1024、1440 和 2200px 宽度，以及浅色、深色和缩放场景。
- 官网明确区分两种使用方式：网页版无需安装；桌面扩展用于自动替换 Chrome 或 Edge 新标签页。
- 本版本不改变数据 schema、同步协议、账号隔离、备份格式或用户数据迁移路径。

## English

- When Home has no sites, it no longer reserves an entire empty canvas column; My Sites becomes a compact add action and widgets use the main content width.
- Existing free-position site canvases remain unchanged after a site is added, preserving saved shortcut positions.
- Settings now owns one vertical scroll region, and every control adapts to its available width without right-side clipping or horizontal scrolling.
- Layout was verified at 375, 768, 1024, 1440, and 2200px, including light, dark, and zoomed views.
- The website now clearly separates the two choices: the web app needs no installation, while the desktop extension automatically replaces Chrome or Edge new tabs.
- This release does not change the data schema, sync protocol, account isolation, backup format, or user-data migration path.
