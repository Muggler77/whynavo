# WhyNavo 0.9.35

WhyNavo 0.9.35 unifies web search across Home and Spaces, consolidates local content discovery, and adds an optional wallpaper blur.

## 中文

- 外观设置新增壁纸雾化开关，点击后立即保存并实时生效；旧数据默认保持原有雾化观感。
- 新设置参与现有字段时钟、云端快照、完整备份和严格数据校验，不改变同步算法或数据架构版本。
- 空间页顶部现在与主页使用相同的 Google/百度网页搜索，并始终在新标签页打开结果，不再过滤空间内容。
- 左侧搜索页集中搜索网站、文件夹、笔记和任务；文件夹结果可直接打开对应空间文件夹，同时保留回车搜索网络。
- Google/百度选择器只显示品牌图标，保留本地化的无障碍名称、提示、列表框语义和完整键盘操作。
- 已检查中英文、浅色与深色、窄屏、减少动态效果和溢出表现。

本版本不新增浏览器权限，不修改云端配置，也不包含 Chrome 商店操作。数据架构版本仍为 1；由于同步设置采用封闭字段校验，双向同步兼容下限随新增壁纸雾化字段提升到 0.9.35，新版仍可读取旧数据与旧备份。

## English

- Adds a wallpaper blur toggle to Appearance. Changes save immediately and apply live; legacy data keeps the previous softened look by default.
- Includes the preference in existing field clocks, cloud snapshots, complete backups, and strict payload validation without changing the synchronization algorithm or schema version.
- Gives Spaces the same Google/Baidu web search as Home, opening results in a new tab instead of filtering Space contents.
- Consolidates site, folder, note, and task discovery in Search. Folder results open the matching Space folder, while Enter still searches the web.
- Reduces Google/Baidu provider controls to clear brand icons while retaining localized accessible names, titles, listbox semantics, and keyboard behavior.
- Verifies Chinese and English, light and dark themes, narrow layouts, reduced motion, and overflow behavior.

This version adds no browser permissions, changes no cloud configuration, and performs no Chrome Web Store operation. The data schema remains version 1. Because synchronized settings use closed-field validation, the two-way sync compatibility floor advances to 0.9.35 with the new wallpaper-blur field; the new client still reads legacy data and backups.
