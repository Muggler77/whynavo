# WhyNavo 0.8.1

## 中文

WhyNavo 0.8.1 按已确认的样张 A 重建主页。它不是旧界面的换色，而是重新定义首屏结构、留白、导航和主组件层级，同时保留现有数据模型、账号隔离、同步冲突保护、右键菜单与拖拽编辑能力。

### 主页与品牌

- 新增通透的视口画布、柔和室内壁纸和独立左侧导航，导航不再挤压中央内容。
- 问候、搜索、站点区和主组件按样张 A 的坐标与比例重新布局。
- 空工作区显示 8 个本地打包的起始站点图标；这些入口只用于空状态展示，不会写入、同步或覆盖用户数据。
- 正式图标改为罗盘标识，并同步生成扩展、网页、PWA 和 maskable 图标尺寸。

### 小组件与交互

- 天气、专注、日历改为三张等高横向卡片，并根据真实天气、任务和日历数据更新内容。
- 天气卡恢复完整预报区；专注卡保留计时器并避免重复展示同一条任务；日历卡支持直接记录当天事项。
- 右键菜单、布局编辑、组件排序、尺寸设置、主题切换、添加网站和资源中心入口继续可用；拖动后的前三个启用组件会真实成为首屏主卡片。
- 自动隐藏导航仅改变透明度，不再通过位移造成鼠标经过时抖动。

### 手机与平板

- 手机使用固定五项底栏，并增加明确的工具和设置入口。
- 页面改为单列内部滚动，底栏不会造成横向溢出，设置对话框可完整滚动。
- 壁纸使用独立移动端资源，起始站点图标全部随安装包提供，减少首屏网络请求。

### 数据安全

- 本版本不改变数据结构，不清空本机数据，也不把空状态示例写入用户数据；仅对从未调整过的旧默认组件顺序做一次样张 A 排序迁移。
- 本机优先、匿名/账号数据分区、账号切换隔离和冲突安全同步逻辑保持不变。
- 升级前仍建议为重要数据保留完整导出备份。

## English

WhyNavo 0.8.1 rebuilds the home workspace from the approved Sample A. This is a structural redesign of the first viewport, spacing, navigation, and primary widgets rather than a color-only refresh. Existing storage, account isolation, conflict-aware sync, context menus, and drag editing remain intact.

### Home and brand

- Adds a translucent viewport canvas, a calm interior wallpaper, and an independent left rail that does not shift the central workspace.
- Repositions the greeting, search, site launcher, and primary widgets to match the approved reference proportions.
- Shows eight locally packaged starter icons only when the workspace is empty. They are presentation-only and are never written to or synchronized with user data.
- Replaces the product icon with a compass mark across extension, web, PWA, and maskable icon sizes.

### Widgets and interaction

- Weather, Focus, and Calendar now form three equal-height horizontal cards backed by real user and weather data.
- Restores the full forecast area, prevents Focus from repeating the same task, and keeps calendar-day editing available.
- Preserves right-click menus, layout editing, widget sorting and sizing, theme controls, site creation, and the resource center. The first three enabled widgets after a drag now become the actual primary cards.
- Auto-hide navigation now fades without translating, avoiding hover jitter.

### Mobile and tablet

- Adds a stable five-item bottom rail plus explicit Tools and Settings access.
- Uses a single-column scrolling workspace without horizontal overflow and keeps settings fully scrollable.
- Ships mobile wallpaper assets and starter site icons locally to reduce first-view network work.

### Data safety

- This release does not change the data schema, erase local data, or persist starter-state examples. It only migrates the untouched legacy default widget order into the Sample A order.
- Local-first storage, anonymous/account partitions, account-switch isolation, and conflict-aware synchronization are unchanged.
- Keep a complete export of important data before any upgrade.
