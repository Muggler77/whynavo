# WhyNavo 0.9.21

## English

- Prevents Cloudflare and browsers from retaining a stale Service Worker during a release.
- Requires the hosted Service Worker to match the release version before the public update is activated.
- Keeps the extension package, web deployment, and update manifest behind the same verified release gate.

## 中文

- 防止 Cloudflare 和浏览器在发布期间继续缓存旧版 Service Worker。
- 只有线上 Service Worker 与发布版本一致后，才会激活公开更新。
- 扩展安装包、网页部署和更新清单继续由同一套发布校验保护。
