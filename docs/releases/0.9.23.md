# WhyNavo 0.9.23

## English

- Fixes the wallpaper picker interaction that placed the current-wallpaper state and daily-rotation control in the same top-right area.
- Makes the entire wallpaper image a single, explicit selection action with a non-interactive Current badge.
- Moves daily-rotation membership into a separate labeled control below each wallpaper so it cannot intercept wallpaper selection.
- Shows the selected wallpaper name in the instant-save confirmation and gives every selection and rotation action a unique accessible label.
- Adds regression checks that prevent wallpaper selection and rotation controls from being overlaid again.

## 中文

- 修复壁纸选择器把“当前壁纸状态”和“每日轮换控制”叠在同一右上角区域的问题。
- 整张壁纸图片现在只执行一个明确动作：选择并立即应用；右上角“当前”仅作为不可点击的状态标记。
- 每日轮换改为壁纸下方带文字的独立按钮，不再截获壁纸选择点击。
- 自动保存提示会显示实际选中的壁纸名称，并为每个选择和轮换操作提供唯一的无障碍标签。
- 增加回归检查，防止以后再次把壁纸选择与轮换控件叠放。
