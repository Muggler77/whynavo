# WhyNavo 0.9.7

## 中文

WhyNavo 0.9.7 修复网站图标在编辑器中可见、保存后却退回文字占位的严重体验问题，并重新设计完整的图标编辑流程。现有网站、文件夹、在线图标、主页位置、笔记、任务、壁纸、账号和同步数据均会保留。

- 图标候选与最终画布现在使用相同的清晰度标准，不再提供保存后无法显示的候选。
- 用户保存图标时会只清除当前网站的旧失败缓存，保存后立即重新加载，不会刷新其他网站图标。
- 图标编辑改为“在线图标、纯色图标、本地上传”三种明确模式。
- 纯色图标支持 20 种配色和 1–2 个自定义字符，适合无法自动获取图标的网站。
- 本地图片会压缩到适合图标使用的尺寸后仅保存在当前设备；其他设备使用同色文字回退，避免把私人图片明文上传。
- 在线图片加载失败时使用网站名称和用户颜色生成清晰占位，不再出现难看的灰色字块。
- 文字、颜色与专用图标更新时间均纳入结构验证、完整备份和多设备同步。
- 最低同步版本提升为 0.9.7，避免旧版客户端忽略新图标字段后覆盖用户选择。

## English

WhyNavo 0.9.7 fixes a major icon workflow issue where an image could appear usable in the editor but fall back to a text placeholder after saving. Existing sites, folders, online icons, Home positions, notes, tasks, wallpapers, account data, and synchronized data are preserved.

- Icon candidates and the final canvas now use the same sharpness requirement.
- Saving an icon invalidates only that site's stale failure cache and reloads it immediately without refreshing unrelated icons.
- Icon editing now provides clear Online, Text, and Local upload modes.
- Text icons support 20 colors and one or two custom characters for sites without a usable icon.
- Uploaded images are compressed to an icon-appropriate size and remain device-local. Other devices use the same-color text fallback so private images are not uploaded in plaintext.
- Failed online images fall back to a clean name-based icon using the user's color instead of an unstyled gray block.
- Text, color, and a dedicated icon refresh timestamp are covered by structural validation, complete backups, and multi-device synchronization.
- The minimum synchronization version is now 0.9.7 so older clients cannot ignore and overwrite the new icon fields.
