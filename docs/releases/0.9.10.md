# WhyNavo 0.9.10

## 中文

WhyNavo 0.9.10 优化大型图标画布的稳定性和页面滚动手感。现有网站、文件夹、主页位置、笔记、任务、小组件、壁纸、账号和同步数据都会保留。

- 用户明确选择的图标会提前加载，并复用本机保存的解析结果；保存后进入空间页或重新打开页面时不再重新轮换候选。
- 普通规模的图标库会作为一个稳定画布挂载，避免向下滚动时每批新增图标造成连续闪烁。
- 超大图标库仍采用分批渲染，预加载距离和每批数量均已提高，在保持内存边界的同时避免滚动追上加载进度。
- 移除滚轮到页面边界时自动切换工作区的行为。滚动只负责滚动，用户明确点击左侧导航时才会换页。
- 图标取消淡入动画，页面切换改为克制的 280ms 缓动，并继续遵循系统的“减少动态效果”设置。

## English

WhyNavo 0.9.10 improves the stability of large icon canvases and the feel of page scrolling. Existing sites, folders, Home positions, notes, tasks, widgets, wallpapers, accounts, and synchronized data are preserved.

- Explicitly selected icons are prepared early and reuse the locally persisted resolution result. They no longer re-enter candidate rotation after saving, opening Spaces, or remounting a page.
- Typical icon collections mount as one stable canvas so scrolling does not reveal successive flashing batches.
- Exceptionally large collections remain batched, with a larger preload distance and batch size to preserve memory limits without letting scrolling outrun preparation.
- Reaching a page boundary with the mouse wheel no longer switches workspaces. Scrolling only scrolls; pages change after an explicit navigation action.
- Icon fade-in has been removed, page changes use a restrained 280ms ease-out transition, and reduced-motion preferences remain respected.
