# WhyNavo 0.8.0

## 中文

WhyNavo 0.8.0 是 Lucid Canvas 全面界面更新。它保留 0.7.0 的本机优先存储、账号隔离和冲突安全同步，不修改现有用户的数据结构。

### 界面与交互

- 按样张 A 重做白天通透的壁纸工作区，搜索框保持屏幕真正居中。
- 桌面导航固定在屏幕最左或最右并垂直居中，不再挤压中央内容。
- 修复自动隐藏导航在鼠标移入边缘时反复开合的问题。
- 主页采用稳定的 12 列布局，小组件按 6+6、6+3+3 等组合排列。
- 重新设计全部小组件表面、层级和信息密度，同时保留每种组件自己的结构。
- 网站图标继续使用高清候选、失败回退、延迟加载和账号级解析缓存。
- 设置、资源中心、账号与同步弹窗在桌面、短屏和手机上均可完整滚动。
- 未登录时账号页只展示登录或注册所需内容，不再显示无关的同步参数。
- 右键菜单、快捷入口拖拽和小组件拖拽继续支持鼠标、触摸与键盘。

### 品牌与性能

- 使用新的 WhyNavo “N + 导航箭头”应用图标，并更新扩展、PWA 和 maskable 图标。
- 新用户默认使用明亮的 Coastal Glass 壁纸和浅色主题；已有用户的主题与数据保持不变。
- 快捷入口分批渲染数量从 80 降为 48，视口外小组件启用浏览器延迟渲染。
- PWA 外部图标缓存仍限制为 200 项，避免缓存无界增长。

### 安全说明

- 此版本没有改变账号数据分区、同步修订校验、登出范围或备份格式。
- 为确保所有公开用户使用同一套交互与安全检查，云同步最低客户端提升为 0.8.0；升级不会清空或重建用户数据。
- 正式开放在线注册前，仍需完成正式邮件发件域名、加密异地备份和生产环境冒烟测试。

## English

WhyNavo 0.8.0 is the Lucid Canvas interface release. It keeps the local-first storage, account isolation, and conflict-aware synchronization introduced in 0.7.0 without changing the user data schema.

### Interface and interaction

- Rebuilds the workspace around the airy daytime direction from Sample A.
- Keeps desktop navigation fixed at the far left or right without shifting the canvas.
- Fixes auto-hide rail jitter and preserves right-click and drag interactions.
- Uses a stable 12-column widget layout with distinct widget surfaces and information structures.
- Makes settings, resources, account, and registration dialogs fully scrollable on desktop, short screens, and mobile.
- Removes connected-account controls from the anonymous login and registration view.

### Brand and performance

- Introduces the new WhyNavo N-and-wayfinding app mark for extension and PWA icons.
- Uses the Coastal Glass light scene for new installations while preserving existing preferences.
- Reduces shortcut render batches from 80 to 48 and defers rendering for off-screen widgets.
- Keeps bounded icon caches and resilient high-resolution icon fallbacks.

### Safety

- Account partitions, revision-checked sync, sign-out scope, and backup formats are unchanged.
- The minimum cloud-sync client is now 0.8.0 so public users receive the same interaction and safety checks; upgrading does not reset user data.
- Public hosted registration remains pre-release until production email, encrypted off-site backup, and live smoke tests are complete.
