# WhyNavo 0.9.0

## 中文

WhyNavo 0.9.0 完成样张 A 的结构级落地。主页不再堆叠同形大卡片，而是以克制的站点区、天气、专注和日历构成第一工作视图；Search、Notes、Tasks、Spaces 和 Tools 则各自承担独立工作流。

### 通透主页

- 桌面画布、视口居中搜索、贴边垂直导航和首屏比例按样张 A 重新校准。
- 主屏只显示一层信息结构：站点入口与三张主组件并列，其他组件进入单项切换区，不再形成第二面卡片墙。
- 天气采用温度、天气弧、关键指标和四日预报；专注采用纸张任务面与计时控制；日历采用周视图和日程列表。
- 站点图标直接填充自身轮廓，不添加额外彩色外框；主页和 Spaces 共用同一尺寸、圆角和加载策略。

### 独立页面

- Search 同时搜索站点、笔记和任务，也可直接进行网络搜索。
- Notes 使用列表与编辑器布局，支持新建、自动保存和删除。
- Tasks 提供进度、筛选、新建、完成和删除操作。
- Spaces 保留完整站点与文件夹管理，Tools 保留现有工具能力，不再伪装成重复主页。

### 可定制导航

- 内置页面支持改名、替换图标、上下排序和显隐。
- Tools 默认收进导航设置，使首屏导航与样张 A 一致；用户可以随时恢复显示。
- 自定义页面继续支持添加、编辑、排序和删除。
- 桌面导航保持贴边垂直居中；手机使用不超过五项的固定底部导航。

### 设置与交互

- 设置重组为外观、导航、数据和版本四个区域，使用统一画布、字段和操作层级。
- 设置内容只有一个滚动区域，底部操作始终可达。
- 右键菜单、组件拖拽、组件尺寸、自动隐藏导航和键盘焦点状态继续保留。
- 自动隐藏只使用透明度和位移，边缘触发区在导航打开时停用，避免鼠标经过抖动。

### 数据兼容

- 数据结构版本保持不变，不删除快捷方式、笔记、任务、组件或账号数据。
- `0.9.0` 只迁移默认视觉布局；用户修改过的组件顺序、尺寸和导航内容继续保留。
- 本机优先存储、匿名与账号分区、账号切换隔离和冲突安全同步逻辑保持不变。

## English

WhyNavo 0.9.0 completes the structural implementation of Sample A. The home view is now a restrained first workspace built from Sites, Weather, Focus, and Calendar rather than a wall of interchangeable cards. Search, Notes, Tasks, Spaces, and Tools each provide a distinct workflow.

### Translucent home

- Recalibrates the desktop canvas, viewport-centered search, edge-aligned rail, and first-view proportions against Sample A.
- Keeps one primary information layer: sites and three primary widgets. Remaining widgets live in a single selectable shelf instead of a second card wall.
- Gives Weather a temperature arc, key conditions, and four-day forecast; Focus a paper task surface and timer; and Calendar a week view with agenda.
- Uses the same filled artwork, size, rounding, and loading behavior for icons on Home and Spaces.

### Dedicated workspaces

- Search covers sites, notes, and tasks and can also launch a web search.
- Notes uses a two-pane list and editor with create, autosave, and delete actions.
- Tasks includes progress, filters, creation, completion, and deletion.
- Spaces retains full site and folder management, while Tools retains the existing utilities instead of duplicating Home.

### Custom navigation

- Built-in destinations can be renamed, reordered, hidden, restored, and assigned a different icon.
- Tools is hidden by default to match Sample A and can be restored at any time.
- Custom pages remain editable, sortable, and removable.
- Desktop navigation stays vertically centered at the screen edge; mobile uses a stable five-item bottom bar.

### Settings and interaction

- Reorganizes Settings into Appearance, Navigation, Data, and Version with one coherent visual language.
- Keeps one scrollable content region and an always-reachable footer.
- Preserves context menus, widget drag ordering, widget sizing, auto-hide navigation, and keyboard focus states.
- Auto-hide relies on opacity and transforms, and disables the edge trigger while open to prevent pointer jitter.

### Data compatibility

- The data schema is unchanged and no shortcut, note, task, widget, or account data is deleted.
- `0.9.0` migrates only default presentation choices; user-customized widget order, sizes, and navigation content remain intact.
- Local-first storage, anonymous and account partitions, account-switch isolation, and conflict-aware synchronization remain unchanged.
