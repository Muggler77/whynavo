WhyNavo Support

Do not place email addresses, account details, verification links, exported backups, private notes, access keys, or screenshots containing personal data in a public issue.

Usage help and general questions

Start with the installation and usage guide. For feature questions or suggestions that contain no personal data, contact the maintainer through GitHub Issues.

Accounts, privacy, and security

Signed-in users can sign out locally, sign out all devices, export a complete backup, or permanently delete the account from the account and sync panel. Submit personal-data requests and security matters through GitHub private vulnerability reporting, never through a public issue.

When reporting a problem

  • Include the WhyNavo version, browser version, operating system, and reproduction steps.
  • Upload only redacted screenshots and sample data.
  • Never send passwords, verification codes, recovery keys, tokens, or a complete backup.
